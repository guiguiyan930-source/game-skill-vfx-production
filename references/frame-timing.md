## F1–F6 职责细则

### 攻击类（F4=命中/峰值）

| 帧 | 职责 | 视觉重点 | 情绪词 |
|---|---|---|---|
| F1 | 起势 / 聚气开始 | 低强度建立形态，明确能量来源 | 蓄势 |
| F2 | 蓄能增强 | 体积 / 粒子密度 / 亮度上升 | 加压 |
| F3 | 释放 / 爆发 / 接近目标 | 方向与速度清晰，为命中蓄势 | 冲刺 |
| F4 | 命中（峰值） | 反馈峰值；轮廓、冲击方向与目标关系明确 | 爆发 |
| F5 | 余波 / 碎片扩散 | 强度回落，保留运动惯性 | 扩散 |
| F6 | 消散 / 结束 | 平滑归零（alpha≈5%）；持续技能衔接循环 | 收尾 |

### 非攻击类（F4=强度峰值/状态建立，需显式标注扩展规则）

| 帧 | 职责 | 示例（治疗光环） |
|---|---|---|
| F1 | 起势 / 出现 | 地面浮现法阵轮廓 |
| F2 | 建立 | 法阵亮度、范围上升 |
| F3 | 建立完成 | 符文清晰、粒子启动 |
| F4 | 强度峰值 / 状态建立 | 光环全亮、呼吸节奏确立 |
| F5 | 稳定循环 | 进入循环段（衔接 F4） |
| F6 | 结束过渡（如需） | 柔和衰减或回到循环起始 |

## 帧数策略

| 用途 | 建议帧数 | fps | 时长 |
|---|---|---|---|
| 待机 / 循环特效 | 8 | 12 | 0.67s |
| 普攻 / 小技能 | 16 | 24 | 0.67s |
| 大招 / 终结技 | 24–32 | 24 | 1.0–1.33s |
| Boss 演出 | 32+ | 30 | ≥ 1.0s |

## 6→N 插值分配

原则：**冲击力段节奏最快，高光段多停帧**；前摇 ≤5 帧，后摇 ≥4 帧（避免"戛然而止"）。

### 16 帧（标准技能）

```
F1 → 1,2,3      (Charge Start × 3)
F2 → 4,5        (Charge Peak × 2)
F3 → 6,7        (Release × 2)      ← 冲击力段，节奏最快
F4 → 8,9,10     (Peak/Hit × 3)     ← 高光多停 1 帧
F5 → 11,12,13   (Aftermath × 3)
F6 → 14,15,16   (Dissipate × 3，最后一帧近透明)
```

### 8 帧（循环 / 小特效）

```
聚气×2 · 释放×1 · 高光×2 · 余波×2 · 消散×1
若 loopable：F1 与 F8 的 alpha/亮度/位置差 < 5%
```

### 24 / 32 帧（大招 / Boss）

- 增加**停顿帧**：Peak 帧重复 2–3 次强化冲击。
- 允许分段：Charge (0–8) · Release (8–12) · Impact (12–20) · Dissipate (20–32)。
- 命中帧通常落在 8–10 帧（16 帧制）或总长的 40%–55%。

## 亮度曲线与命中帧

- 亮度曲线呈「低-中-高-高-中-低」抛物线，**峰值落在 hit_frame**。
- hit_frame 与 `timing.hit_frame`（0-indexed）一致；生成后回读校验。
- 相邻帧位移 ≤ 15% 画布宽度，避免"跳"。
- 粒子生命周期覆盖完整：出生 → 运动 → 消亡。

## 循环特效处理

- `loopable: true` 时：F1 与 Fn 的 alpha/亮度/位置像素差 < 5%。
- 旋转类：旋转角必须是 360° 的整数倍（闭环）。
- 持续类（E7）：首帧 = 末帧画面，中间用 sin 呼吸曲线。

## 非命中类模板

**光环 / 治疗 / 持续循环（8 帧）**：

```
F1-F2 建立（亮度 40%→70%）
F3-F4 峰值（亮度 100%，停顿）
F5-F6 回落（70%）
F7-F8 缓升（85%→100%）   ← 呼吸感，F8≈F4 但粒子相位偏移
```

**消散模板（3–6 帧）**：

```
alpha: 100% → 60% → 25% → 8% → 2%
最后 2–3 帧必须保留 alpha 渐变，禁止直接删帧
```

## 连续性三原则量化

| 原则 | 量化标准 | 检验方法 |
|---|---|---|
| 相机锁定 | 同机位、同 FOV、同光源方向 | 关键结构线对齐 |
| 锚点稳定 | pivot 位移 ≤ 帧宽 10% | bbox 校验（脚本） |
| 色相守恒 | 相邻帧主色相差 ≤ 60°；跨阶段允许一次大跳 | HSV 采样对比 |
