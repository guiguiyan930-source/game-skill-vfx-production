## 7 维验收清单

Stage 5 强制逐项打钩；未通过项必须写明原因与修复动作，修复后重跑 `scripts/validate_sequence.py` 并复检。

### 视觉
- [ ] 配色与元素锁定一致（对照 style_lock.md），无明显形态漂移
- [ ] 峰值帧清楚（亮度最高帧 = hit_frame）
- [ ] 不遮挡关键玩法信息（角色、文字、操作目标）
- [ ] 深浅两种背景上均无黑边/白边

### 时序
- [ ] 起手、命中、收尾与玩法事件匹配（cast/active/recover/hit_frame）
- [ ] 循环无跳变（loopable=true 时首尾差 < 5%）
- [ ] 可正确中断与清理（播放中途取消不残留）

### 透明
- [ ] 全部帧 RGBA 8-bit
- [ ] 四角 alpha=0
- [ ] 边缘无残留色（绿/黑/紫边）
- [ ] 半透明细节保留（光晕/烟有渐变，非二值化）
- [ ] 棋盘格预览通过

### 资源
- [ ] 尺寸、编号、帧数、路径与元数据一致
- [ ] 无漏帧（04_frames 数量 = meta.frame_count）
- [ ] 锚点无抖动（bbox 一致）
- [ ] 命名符合 `fx_{skill}_{phase}_{variant}_v{ver}_{frame:04d}.png`

### 工程
- [ ] 材质匹配 straight / premultiplied Alpha（与 meta 一致）
- [ ] 混合模式（alpha / additive）与层级正确
- [ ] 缩放与 pivot 正确（引擎实测）

### 性能
- [ ] 在目标设备记录：同屏数量、帧耗时、内存、透明过绘
- [ ] 按项目预算验收；显存估算 = 宽×高×4×帧数 在预算内
- [ ] 必要时降级方案：降尺寸/帧率/换图集/改用 additive 合并

### 体验
- [ ] 高亮闪烁与震动可控（有强度档位）
- [ ] 弱化动效模式（reduce motion）下重要提示仍可见
- [ ] 全年龄合规（对照 constraints）

## 质量分级

| 等级 | 标准 |
|---|---|
| S 级 | 7 维全通过 + 反面案例 0 命中 + 引擎实测流畅 |
| A 级 | 7 维全通过，反面 ≤1 处非致命 |
| B 级 | 视觉/时序/透明通过，资源/工程有小瑕疵可修 |
| 不合格 | Alpha 有残留 / 帧数与 meta 不符 / 未过 storyboard 门禁 / 漏帧 |

不合格必须回对应阶段修复，禁止交付。

## 反面案例

| ❌ 反面 | 症状 | ✅ 正确做法 |
|---|---|---|
| 跳过 storyboard 直出 16 帧 | 节奏错乱，返工 3 次 | 强制 Stage 2 门禁，先 6 帧对齐 |
| 抠图边缘绿边 | 引擎中主体外一圈绿光 | Defringe + 边缘采样自检 |
| 帧间 bbox 不一 | 播放时主体"跳动" | 全帧 alpha 并集统一裁剪 + 4px padding |
| 最后一帧直接删 | 特效"啪"消失 | 最后 2–3 帧 alpha 线性衰减到 5% |
| 白闪 6 帧 | 命中感糊掉 | 白闪 ≤ 2 帧，其后接冲击环 |
| loopable 但首尾差异大 | 循环时"闪一下" | F1=Fn，差异 < 5% |
| 预乘 alpha 但引擎按非预乘处理 | 半透明变暗 | meta 声明 alpha_mode，双版本导出 |
| 帧文件名带中文/空格/大写 | Unity/Godot 加载失败 | 全小写 snake_case + 零填充 |
| 拖尾长度恒定 | 弹道假、无速度感 | 拖尾长度 = f(速度)，末尾 ease-out |
| 消散帧色相不变 | 观感"没结束" | 消散帧降饱和 + 降亮度 |
| MP4 当透明母版 | 引擎里带黑底 | 用 RGBA PNG 序列/含 alpha 编码，MP4 仅预览 |
| 帧序列九宫格拉伸 | 形态扭曲 | 帧序列特效禁止九宫格，静态面板才用 |
